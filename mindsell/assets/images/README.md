# Image Assets

Place the following image files in this folder.

## Required files

| File | Size | Description |
|------|------|-------------|
| `icon.png` | 1024×1024 | App icon — dark background #0A0906, MindSell monogram |
| `splash.png` | 1284×2778 | Splash screen — dark, minimal |
| `adaptive-icon.png` | 1024×1024 | Android adaptive icon foreground |
| `favicon.png` | 48×48 | Web favicon |

## Quick generation

You can generate placeholder icons with any design tool or use:
```bash
npx expo install expo-image
# or simply use solid-color placeholders during development
```

Background color for all assets: `#0A0906`
Accent color: `#E8A87C` (gold)
